## Core rule

**Labels describe operator cognition, not information architecture.**

| Bad (IA) | Good (cognition) |
|----------|------------------|
| DEEP READ | WHEN SIGNAL IS UNCLEAR ↓ |
| ADVANCED | WHEN STRUCTURE BREAKS ↓ |
| MORE | CONTEXT ↓ |
| DETAILS | EXPERIMENT SYSTEMS ↓ |
| SECTION 2 | FRICTION AUDIT ↓ |
| EXPAND | DECISIONS ↓ |
| METADATA | OBSERVED TRAITS ↓ |

The operator should know **when** to open a block, not **how the file is organized**.

---

## Collapse suffix

**↓** (and **↑** when expanded) on disclosure headers — mono, same family as section kickers.

- Collapsed: `WHEN SIGNAL IS UNCLEAR ↓`  
- Expanded: `WHEN SIGNAL IS UNCLEAR ↑` or shortened title without arrow (either is acceptable if consistent within surface)

**Do not use** “tap to expand,” “learn more,” “show details” — the label carries the affordance.

---

## Where tiering is allowed

| Surface | Tiering |
|---------|---------|
| **Manual → crash course** | READ THIS FIRST · WHEN SIGNAL IS UNCLEAR ↓ ✓ |
| **Hideout dashboard** | TODAY AT HIDEOUT · EXPERIMENT SYSTEMS ↓ · FRICTION AUDIT ↓ · DECISIONS ↓ ✓ |
| **Now (phone)** | OPERATING PRIORITY · CONTEXT ↓ ✓ |
| **Intel** | TRAITS ↓ · WHEN STRUCTURE BREAKS ↓ ✓ |
| **Today / Signal execute** | No READ THIS FIRST ✗ |
| **Logging sheets** | Purpose line only — one literal sentence ✗ |

**Rule:** Tutorial framing is for **learning and diagnosis surfaces**, not execution.

## Mono kicker conventions

- ALL CAPS · tracked · `MonoLabel`  
- Short — prefer 2–4 words  
- Domain color only when it aids scan (warm Hideout, inkGreen traits, inkAmber failure)  
- Not every card needs a kicker — silence OK  

**SectionHeader** vs **MonoLabel:** SectionHeader for lists (SHIFT LOG); MonoLabel for semantic bands.

---

## Literal chrome (execute surfaces)

Use plain operational words:

- Rest · Skip · Finish · Log · Save · Edit  
- Day numbers, band names, dollar amounts when data exists  
- No metaphor on buttons (“ignite,” “crush,” “launch your day”)

---

## Domain-specific cognition headers (examples)

When adding new collapse blocks, name the **operator moment**:

| Domain | Example header |
|--------|----------------|
| Recovery | WHEN THE LEG FEELS OFF ↓ |
| Physique | WHEN ADHERENCE BREAKS ↓ |
| Hideout | WHEN REVENUE FEELS SOFT ↓ |
| Capital | WHEN RUNWAY TIGHTENS ↓ |

Do not copy Hideout headers into other domains verbatim — **pattern**, not template spam.

---

## Numbers and data copy

- Prefer **meaning before raw number** when system can infer (Master: interpretation over data)  
- When number is the read (Hideout gross, repeat %), show it — mono, large  
- Empty → em dash or omission — not “N/A” filler  

---

## Anti-patterns

- READ THIS FIRST on every screen  
- Lorem-style placeholder intelligence  
- Framework words on labels: FRICTION ONTOLOGY, LAYER B, PARTICIPATION GAP  
- Exclamation marks in product UI  
- Emoji in operator surfaces
