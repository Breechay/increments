# INCREMENTS — Content Topology

**Version:** May 2026  
**Status:** Canonical

Where content types live — prevents doctrine entropy, duplicate shells, and execution surfaces becoming reading surfaces.

---

## Content types

| Type | Stability | Operator question | Mutability |
|------|-----------|-------------------|------------|
| **Doctrine** | Stable truth | What is true this season? | Rare — deliberate edits |
| **Current state** | This week / today | What is happening now? | Daily / weekly |
| **Diagnosis** | When unclear | What structural failure is active? | On demand |
| **Execution** | Now | What do I do next? | Per session |
| **Archive / lookup** | Reference | What is the protocol/spec? | Versioned, infrequent |
| **Experiment** | Provisional | What hypothesis is running? | Close when data decides |

---

| Type | Primary home | Secondary |

## You tab topology (evening)

```
You
├── Capital          → stewardship truth (current + structural)
├── Brief            → situation room + Wendy (current interpret)
├── Doctrine         → stable reads (operator, distribution, hideout, FORM)
├── Ventures         → per-venture live signal (current)
├── Intel            → traits + failure modes (diagnosis, collapsed)
└── Manual           → principles + crash course (doctrine + learn)
    ├── entries      → lookup by topic
    └── crash course
        ├── READ THIS FIRST        (doctrine/core loop)
        └── WHEN SIGNAL IS UNCLEAR ↓ (depth)
```

**Settings (gear):** configuration export — not intelligence content.

## Hideout topology

```
Hideout
├── Dashboard
│   ├── TODAY AT HIDEOUT     (current — always)
│   ├── EXPERIMENT SYSTEMS ↓ (experiment)
│   ├── FRICTION AUDIT ↓     (current checklist)
│   └── DECISIONS ↓          (doctrine-adjacent decision stack)
```

Pre-open operator should not scroll through Sunday strategy to log yesterday’s shift.

## Today vs Now

|---------|----------------------------------|

## Manual vs Doctrine tab

| | Doctrine tab | Manual |
|--|--------------|--------|
| **Shape** | Long-form season reads | Entry list + crash course |
| **Voice** | Authoritative, seasonal | “When stuck” + distribution learn |
| **Reading** | Nonlinear section pick | Expand per entry + tiered course |

Overlap is intentional — Manual is **operational lookup**; Doctrine is **season architecture**.

Do not duplicate full Doctrine bodies into Manual without reason.

---

## Crash course tiering (content rule)

**Tier 1 — READ THIS FIRST**  
Only what must be true to run the loop (farming, definition, mental shift, reps/signal/adjust, Monday block).

**Tier 2 — WHEN SIGNAL IS UNCLEAR ↓**  
Venture paths, ambiguity, failures, surfaces — depth for learning pass, not Monday 6:45am.

Operator psychology that explains *why the loop breaks* belongs in **Doctrine → Operator**, not tier 1 crash course (shipped May 2026).

## Authored content audit

`YOU_TAB_AUTHORED_CONTENT_AUDIT.md` — export of shipped strings for review.  
Update when large authored passes land; not runtime source of truth.

## What does not belong in app UI

- Agent-only markdown dumps on execute tabs  
- Archived Master versions  
- Psych PDFs from `Psych/` — reference material, not in-app doctrine  
- hideout-ops-console dashboards  

---

## Content drift guards

1. New long-form text → classify type first (table above)  
2. If doctrine → You → Doctrine or Manual, not Today  
3. If provisional → label experiment; date the hypothesis  
4. If duplicate shell (second Dossier) → delete, don’t fork  
5. Collapse by default when reread is occasional  

---

## Archive policy

`Archive/Past-Docs/` — archaeology only.  
Never implement navigation from archive specs without explicit task.
